# AGENTS.md

Orientações para agentes de IA trabalharem neste repositório.

## Sobre o projeto

CompilaNews é uma plataforma aberta de curadoria e agregação de conteúdo voltada para tecnologia e programação. O projeto usa Next.js e React para apresentar artigos e discussões relevantes da comunidade de forma organizada e livre de ruídos.

## Stack

- **Next.js** com App Router
- **React** / react-dom

Versões exatas e dependências instaladas estão em `package.json`.

## Estrutura

O código da aplicação fica em `/app`, seguindo as convenções do App Router do Next.js.

## Comandos

```bash
npm install   	# instalar dependências
npm run dev			# iniciar o servidor de desenvolvimento
npm run build		# gerar a build de produção
npm start				# iniciar a aplicação após a buil
```
